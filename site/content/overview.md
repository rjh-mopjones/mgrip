# Margin's Grip

3D voxel open-world survival RPG set on Margin, a tidally locked planet. Godot 4.3 with a Rust GDExtension for terrain generation.

Current state: terrain and runtime only. No gameplay systems yet.

## Status

| Area | State |
|---|---|
| Terrain generation | Working. Noise layers, biomes, rivers. |
| Chunk streaming and LOD | Working. |
| Player movement | Working. Walk, fly, swim. |
| Agent playtest runtime | Working. Developer only. |
| Browser build | Working locally. Not deployed. |
| Inventory, crafting, combat, quests | Not started. |
| World simulation | Designed, not built. |

## Play

Pick a spawn point on the [map](/map/). Runs in the browser.
